# Max's Life Science Chapter 1 Quiz

An interactive practice quiz for BJU Press Life Science, Chapter 1: God's Living World (sections 1.1 through 1.9).

- 62 questions, 83 points, every one multiple choice, true/false, or picked from a word bank
- Graded instantly with the correct answer shown for anything missed
- 90% or higher: fireworks and a cheer. Anything less: a womp womp and a very large fart
- Progress and best score are saved in the browser

The whole quiz is one file, `index.html`, with no dependencies beyond Google Fonts.

## Run it

Open `index.html` in any browser, or turn on GitHub Pages for this repo (Settings, Pages, deploy from the `main` branch, root folder) and share the link.
